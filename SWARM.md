# Swarm coordination

This file records runtime coordination for active work only. It is not project
history.

## Rules

- Keep no more than three live handoffs.
- Keep each handoff to 50 words or fewer.
- Put cross-agent communication only in this file.
- Delete completed handoffs; do not archive them here.
- Record durable architectural and engineering decisions in the canonical
  decision or architecture documents.
- Use Git history to record implementation changes.
- Use code comments only to explain code behavior or reasoning. Never put agent
  conversation, handoffs, PM instructions, implementation history, or authorship
  notes in code comments.
