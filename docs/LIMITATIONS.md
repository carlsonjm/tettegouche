# Known limits

What Tettegouche does not do yet, and what it will not do.

## Not planned

- **Ambient:** camera or microphone in use, phone calls through KDE Connect, and
  system updates installing.
- **Files:** split view, a terminal panel, a folder tree and information panels,
  list and details views, permanent delete outside Trash, acting as
  administrator, tags and ratings, batch rename, version
  control, and browsing inside archives.
